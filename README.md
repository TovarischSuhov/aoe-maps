# aoe-maps

Random Map Scripts (RMS) for Age of Empires II: DE.

Projects:

- **Open Arabia** — a rework of standard Arabia's food, gold and stone
  distribution so the map plays open and forces an aggressive Feudal Age
  instead of a walled-up game. Requirements and open questions live in
  [`docs/arabia-open.tz.md`](docs/arabia-open.tz.md). Status: work in progress.
- **StandartRandom** — a mod with six Random Map scripts: one general pick
  among 100 standard AoE2: DE maps plus five themed randoms — open, nomad,
  closed, water and hybrid — classified by the game's own `maps.json` flags
  (a map with several tags joins several themed randoms). The maps are not
  copied: the scripts reference the game's own `.rms` files via
  `#include_drs`. Sources in
  [`maps/Standart*.rms`](maps/StandartRandom.rms), generated by
  [`tools/generate-specialized.mjs`](tools/generate-specialized.mjs), mod
  package in [`mod/StandartRandom/`](mod/StandartRandom/).
- **FrozenLake** — an in-progress single map experiment: a circular frozen
  lake with a periodic frost aura announced by a top-panel notice. In
  Regicide games a king's death detonates a saboteur blast ("Explosive
  King"); standard Random Map games play without the gimmick. The lake is
  drawn compact on Tiny so two players fit comfortably.
  ([`maps/FrozenLake.rms`](maps/FrozenLake.rms) + `FrozenLake.xs`).
- **DynamicRMS** — a mod collecting dynamic (XS-scripted) maps with detailed
  per-map descriptions; FrozenLake ships first. Sources in
  [`mod/DynamicRMS/`](mod/DynamicRMS/), package built by `build.sh`
  (each map ships as a `.rms` + `.xs` pair). Status: scaffold, unpublished.

Developed with the
[`aoe2-lsp`](https://github.com/TovarischSuhov/aoe-rms-lsp) language server
(navigation, diagnostics; gate via `tools/lsp-check.mjs` or `cmd/corpus`).
