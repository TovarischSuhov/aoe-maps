# aoe-maps

Random Map Scripts (RMS) for Age of Empires II: DE.

First project — **Open Arabia**: a rework of standard Arabia's food, gold and
stone distribution so the map plays open and forces an aggressive Feudal Age
instead of a walled-up game.

Status: work in progress. Requirements and open questions live in
[`docs/arabia-open.tz.md`](docs/arabia-open.tz.md).

Developed with the
[`aoe2-lsp`](https://github.com/TovarischSuhov/aoe-rms-lsp) language server
(navigation, diagnostics).
