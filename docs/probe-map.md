# ProbeMap — пробная карта для проверки API

Статус: установлена в профиль (18.11.2026), ждёт прогона в игре.
Не входит в мод DynamicRMS — только локальные тесты.

## Что проверяет и за что отвечает

| Проба | Вопрос | На какую идею влияет |
|---|---|---|
| P0–P1 | `xsGetPlayerUnitIds` (+по objectId), `xsGetUnitPosition` | Монумент, Волны, Приливы |
| P2 | `xsGetMapTileAttribute` — отличает ли воду от земли (скан 0..15) | Приливы |
| P3–P4 | ауры: `cLineOfSight`, `cMaxRange` (контроль `cRegenerationRate`) | Песчаная буря |
| P5 | `xsSetUnitOwner` + `xsSetUnitCaption` | Монумент |
| P6–P7 | `xsCreateUnit` → `xsTaskUnits` (движение) → `xsRemoveUnit` | Волны |

## Как запускать

1. `maps/ProbeMap.rms` + `maps/ProbeMap.xs` уже в профиле
   (`random-map-scripts/` и `_common/xs/` соответственно);
2. одиночная игра → Random Map → выбрать ProbeMap (размер любой, 1 игрок);
3. в чате появятся строки `[PRB] P0…P7` с шагом ~2.5 с; карта маленькая,
   партия минутная — результат целиком за первый цикл ауры не нужен,
   просто читать чат.

## Как читать результаты

- **P4 «after los=» изменился против P3 «before»** → ауры поддерживают LOS
  → SandSea в варианте «−обзор/−дальность»; не изменился → деградировать
  на урон/замедление.
- **P2 перечислил отличающиеся атрибуты** → номер атрибута с террейном
  найден эмпирически → используем его для проверки «косяк на воде»;
  тишина → тайл-атрибуты 0..15 не различают — искать ID в новых версиях
  Constants.xs.
- **P5 «player1 tents now = 1»** → захват монумента через `xsSetUnitOwner`
  работает; FAIL → альтернатива — Transform-объекты по владельцу.
- **P7 «moved=OK»** → приказы спавна работают → волны мародёров управляемы.
- Любой FAIL — записать строку чата в этот файл ниже.
