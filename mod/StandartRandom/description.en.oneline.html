StandartRandom is a single Random Map script that picks one of 99 standard Age of Empires II: Definitive Edition maps.

The maps are not copied. The script references the game's own .rms files by name through #include_drs and only randomises which one is loaded, so every map always matches the current game patch and no game files are redistributed.

How it works

  • 99 maps, each with a 1% chance — 99 branches, the maximum the RMS percentage system supports.
  • Only standard random-style maps: no Battle Royale, Escalation Mode or Capture the Relic.
  • Works with any map size and player count that the chosen standard map supports.

Not included

28 standard maps from the newest and most niche parts of the pool were left out to stay within the 99-branch limit. All of them remain available as normal standard maps. MegaRandom is excluded on purpose: this script is already a random pick, so a second layer of randomness was not wanted.

Compatibility

  • Age of Empires II: Definitive Edition, current version.
  • Random map; single-player and multiplayer.
  • Every player in a lobby needs the mod (or the same .rms file). The referenced standard maps are part of the base game.

Installation

Subscribe to the mod, enable it in the in-game Mod Manager, then select StandartRandom in the map list.

Manual install: put StandartRandom.rms into resources/_common/random-map-scripts/ inside your game profile folder.

Uninstallation

Disable or unsubscribe the mod. For a manual install, delete StandartRandom.rms.
