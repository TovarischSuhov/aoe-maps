# Устройство проекта и цикл работы над картой

`aoe-maps` — репозиторий Random Map Scritps (RMS) для Age of Empires II: DE.
Единственный текущий проект — **открытая Аравия** (`arabia-open`): переработка
еды, золота и камня стандартной Аравии так, чтобы карта игралась открыто и
вынуждала агрессивный феодал. Кандидат на площадку rusaok. Требования —
`docs/arabia-open.tz.md` (см. [контракт требований](/contracts/arabia-open-requirements.md)).

## Каталоги

- `maps/` — сами `.rms`; целевой файл проекта — `maps/arabia-open.rms`:
  плоская (`self-contained`) основа, собранная из официальной DE-Аравии
  развёртыванием include-замыкания (см.
  [модель ресурсов](/reference/de-arabia-resource-model.md)). Переработка
  ресурсов ещё не внесена.
- `refs/` — референсные карты и выписки. Сюда же локально извлекается
  официальная Аравия из игры (`refs/game/`); каталог в `.gitignore` — файлы
  игры не коммитятся (см. ниже).
- `docs/` — ТЗ, разборы, журнал наблюдений за LSP (`docs/lsp-issues.md`).
- `knowledge/` — база инженерных знаний (формат OKF v0.2; правила ведения — в
  `AGENTS.md`).

## Инструменты

- **RMS** — язык карт; `random_map.def` подключается движком автоматически.
- **`aoe2-lsp`** (внешний репо
  [`aoe-rms-lsp`](https://github.com/TovarischSuhov/aoe-rms-lsp)) — LSP-сервер:
  навигация (goToDefinition/references/hover/symbols) и диагностика по `.rms`.
  Подключён к Claude Code плагином `aoe2-lsp@aoe2-local` (project scope,
  `.claude/settings.json`; сам маркетплейс `aoe2-local` зарегистрирован в
  user-scope на конкретной машине и указывает на локальный путь).
- **Гейт проверки** — `aoe2-lsp/cmd/corpus`: прогон бинарника сервера по
  каталогу с `.rms`/`.xs`. См. [проверку карты](/runbooks/verification.md).

## Цикл работы

1. Требования фиксируются в `docs/`, не в переписке.
2. Правки `.rms` идут маленькими проверяемыми шагами; каждый шаг прогоняется
   через LSP.
3. После сборки карты — прогон на чистую диагностику и проверка в игре
   (Scenario Editor / партия против ИИ).
4. Внешняя оценка на площадке rusaok.

## Ограничения и договорённости

- **Репо открытый**: секретов нет; приватную переписку и чужие данные в файлы
  не тащим — требования излагаем своими словами (`docs/arabia-open.tz.md`).
- **Файлы игры не коммитятся.** `refs/game/` — локальное извлечение из
  установки AoE2:DE; содержимое защищено копирайтом Forgotten
  Empires/Microsoft, поэтому в `.gitignore`. Тот же принцип у `aoe-rms-lsp`:
  скачанные корпусные скрипты не коммитятся, только список источников.
- **База — официальная.** За основу взята официальная DE-Аравия (`Arabia.rms`
  v3.3, извлечена в `refs/game/`). ТЗ ссылается на `007__Arabia.rms` из корпуса
  `aoe-rms-lsp` — это не та карта; числа ТЗ надо пересчитать (см.
  [модель ресурсов DE-Аравии](/reference/de-arabia-resource-model.md)).
- **Слепая зона проверки.** Официальная карта собрана на `#include_drs`, а LSP
  это замыкание не разворачивает, поэтому модульная карта даёт «ноль
  диагностик» без реального анализа — см.
  [проверку карты](/runbooks/verification.md) и `docs/lsp-issues.md`. Поэтому
  рабочая карта держится **плоской**: include-замыкание разворачивается
  скриптом, и LSP анализирует файл целиком.
